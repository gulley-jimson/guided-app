Concepts · Unity platformer
Chat Projects Roadmap Concepts
GameObject
Every visible thing in the scene — your player, the platforms, the camera. Containers for Components.
Component
Behaviors and properties attached to a GameObject. A sprite, a script, a collider — each is a Component.
Rigidbody2D
Gives a GameObject physics — gravity, velocity, forces. Add it to your character so it falls and moves.
Collider2D
The shape used to detect overlap. BoxCollider2D for platforms, CapsuleCollider2D for the player.
